Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau is a method meant to evaluate polynomials in a Bezier Curve. How my evaluation function works is that it takes in n points along a bezier curve, and uses linear interpolation to compute the n-1 points on the next subdivision. The function follows the following equation: \[p_i' = \text{lerp}(p_i, p_{i+1}, t) = (1 - t)p_i + tp_{i+1}\]

Part 6: Loop subdivision for mesh upsampling

Loopsubdivision is a mesh 3D upsampling algorithm that centers around first subdividing each triangle into 4 smaller triangles, and updating the vertices of the subdivided mesh according to weights. For my implementation I split this operation into 5 steps: First, given an input mesh, I compute the new position of all the vetrices in the mesh, using the subdivision rule shown in the diagram above. Next, I also compute the updated position of all vertices connected to an existing edge. These steps ensure that for the actual subdivision we can go through a complete mesh instead of a series of subdivided meshes. Finally, we iterate through every edge and call a split function on it, then flip any edge that connects a new and old vertex. Finally, we copy all of these computed updates to the actual vertex positions to produce the subdivided mesh.
