Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau is a method meant to evaluate polynomials in a Bezier Curve. How my evaluation function works is that it takes in n points along a bezier curve, and uses linear interpolation to compute the n-1 points on the next subdivision. The function follows the following equation: \[p_i' = \text{lerp}(p_i, p_{i+1}, t) = (1 - t)p_i + tp_{i+1}\]

Part 2: Bezier surfaces with separable 1D de Casteljau

De Casteljau's algorithm extends seamlessly to bezier surfaces, as the transition from 2D to 3D just means that's there's an additional coordinate per controlPoint so the math is the same. To implement this, I modified the original function to incorporate the third point, but instead it serves as a helper function to a recursive algorithm that will find the final point at the last subdivison. Then, to build the teapot below, we consider a grid of n x n control points P_ij. If we are given a parameters u and v, we parameters each row P_i0,...,P_i(n-1) by u then use our recursive algorithm to get the final point P_i per row. We then parameterize each P_i by v and use the recursive function to find point P, which is the point that lies on the Bezier surface given u and v.
