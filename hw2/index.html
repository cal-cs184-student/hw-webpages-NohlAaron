Section I: Bezier Curves and Surfaces

Part 1: Bezier curves with 1D de Casteljau subdivision

De Casteljau is a method meant to evaluate polynomials in a Bezier Curve. How my evaluation function works is that it takes in n points along a bezier curve, and uses linear interpolation to compute the n-1 points on the next subdivision. The function follows the following equation: \[p_i' = \text{lerp}(p_i, p_{i+1}, t) = (1 - t)p_i + tp_{i+1}\]

Part 2: Bezier surfaces with separable 1D de Casteljau

De Casteljau's algorithm extends seamlessly to bezier surfaces, as the transition from 2D to 3D just means that's there's an additional coordinate per controlPoint so the math is the same. To implement this, I modified the original function to incorporate the third point, but instead it serves as a helper function to a recursive algorithm that will find the final point at the last subdivison. Then, to build the teapot below, we consider a grid of n x n control points Pij. If we are given a parameters u and v, we parameters each row Pi0,...,Pi(n-1) by u then use our recursive algorithm to get the final point Pi per row. We then parameterize each Pi by v and use the recursive function to find point P, which is the point that lies on the Bezier surface given u and v.

Part 4: Edge flip

The Edge flip operation will take a shared edge between 2 triangle pairs, and swap their shared edge to be between the isolated corners. See the image below for reference: How my implementation works is that when a shared edge is selected, I will save the 5 edges and 4 points as variables within the function, and then reassign pointers of the shared edge to be between the new shared edges. Afterwards, I then reassign the neighbor points to the original shared edge and reconstruct the face cycles for both triangles to ensure they still point counter clockwise. One part of my debugging journey was reassigning the twin edges along with the original edges, as only adjusting pointers and not the twins causes issues with building the new faces.
